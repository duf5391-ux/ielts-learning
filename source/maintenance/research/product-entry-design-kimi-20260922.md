## 一、设计目标与判定标准

用户要的是一句话：**常用的东西独立摆出来，学习内容一眼能看到、几步能进去**。翻译成可验收的产品标准：

1. **从任何页面出发，到达任何一类学习内容不超过 3 次点击**（手机同样，滚动不计点击）。
2. **每个一级入口点开后的第一屏就是内容或可执行动作**，不是说明文字、不是大卡片里再套小卡片、不是再一层目录。
3. **单词、复习、句子、写作工作台是独立入口**，不再藏在记录页或工作台卡片里。
4. **学习内容扁平可检索**：一个搜索框 + 按科目平铺的分组列表，内容项直接列出，不嵌套。
5. **入口总数有上限**：全局导航 8 项，不因为「独立呈现」无限加入口。低频功能收纳，不占主导航。

权重分级（决定谁上主导航、谁收纳）：

| 权重 | 使用频率 | 功能 | 位置 |
|---|---|---|---|
| 高频 | 每天多次 | 学习、单词、复习、句子 | 主导航前 4 位，手机底栏直达 |
| 中频 | 每天一次或隔天 | 练习、测试、写作工作台 | 主导航 5–7 位，手机「更多」内前 3 项 |
| 低频 | 每周或更低 | 资料管理、记录备份、原始资料、定制课程（待开放）、开发维护 | 工作台内，不占主导航、不占学习任务 |

## 二、全局导航：具体文字与分组

### 2.1 桌面（1440px）左侧栏，自上而下

```text
┌─────────────────────┐
│  i.  IELTS          │
│      我的备考工作区  │
├─────────────────────┤
│  学习               │  ← 首页：今天 + 全部学习内容索引
│  单词               │  ← 我的单词表 + 词卡新学 + 查词历史
│  复习               │  ← 到期队列：单词 / 句子 / 精读回顾
│  句子               │  ← 我的句子本，每条带来源回材料
│  练习               │  ← 四科题组（含阅读精读、写作案例）
│  测试               │  ← 四科整科自测 + 四科组合
│  写作工作台          │  ← 全部写作题的提纲→首稿→修订链路
│  工作台             │  ← 资料 · 记录备份 · 定制课程（待开放）· 开发
└─────────────────────┘
```

与现状的差异：单词、复习、句子从「工作台 → 记录页内嵌」提为一级；写作工作台从工作台八卡之一提为一级；「今天选的内容」「直接开始学习」不再是一级侧栏按钮，收进「学习」第一屏（它们是学习的一个动作，不是和学习并列的东西）；「开发工作台」收进「工作台」底部一条链接。

### 2.2 手机（390px）

- **底部固定直达条 5 键**：`学习 · 单词 · 复习 · 句子 · 更多`。高频四件一键即达，符合用户「单独丢出来」的原话。
- **「更多」打开抽屉**，自上而下：`练习 / 测试 / 写作工作台 / 工作台`。抽屉是平铺列表，不是折叠目录。
- 顶栏只放：菜单（等同于「更多」）、当前位置（一处标题，不重复）、保存状态点。底栏直达条不遮挡输入区和录音控件，学习内容页滚动时底栏保持可见（它是导航，不是广告条）。

### 2.3 导航文案与既有语义对应（防歧义）

- 「复习」= 到期重看队列（单词复习与拼写、句子重看、材料精读回顾），与「学习」里的新内容明确分开。它**不等于**每日安排，也不自动清空。
- 「单词」= 我的积累（单词表 + 复习入口 + 查词历史），1000 话题词卡作为「新学词卡」区在单词页内；词卡收藏与正文查词收藏接通同一份单词表（承接 P0-02，本方案的第一屏依赖它成立）。
- 「工作台」改名不换义：现在是「学习工作台」混装学习活动；本方案后它只装资料和记录，侧栏就叫「工作台」，页头写「资料与记录」。

## 三、每个一级入口的第一屏与完整链路

约定：每节按「入口 → 首屏 → 找到具体内容 → 进入内容 → 返回」五步写清。所有「继续上次」必须指向真实对象并写明它续的是什么（单元 / 会话 / 某题阶段），不允许再出现两套「继续」无说明并存。

### 3.1 学习（首页）

- **入口**：侧栏第 1 位 / 手机底栏第 1 键 / 品牌 logo。
- **首屏**（自上而下，说明全部收起）：
  1. **今天条**：一行。「今天的安排：已完成 2/4 步 · 继续这次学习 →」；没有安排时是「直接开始：选 15/30/60 分钟 →」。每日安排（daily-study）只在这里出现，不再占侧栏。
  2. **继续上次**：一行。「上次学到《The Davies Sisters · 首次作答》 →」。若无则整行不显示，不占位。
  3. **自选清单**：一行。「自选清单 · 3 项 →」（长期清单，文案写明「保留到你手动移除，不会自动变成今天的安排」）。
  4. **搜索框**：占位文字「搜索全部学习内容：听力、阅读、写作、口语、词汇、精读……」。搜索覆盖全部 227 单元 + 38 组精读 + 写作题 + 词卡话题，结果行直接点进内容。
  5. **内容索引**：按科目平铺分组，每组是小标题 + 直接的内容行列表（不是卡片网格）：
     - 听力 · 7｜阅读 · 15｜写作 Task 1 · 10｜写作 Task 2 · 6｜口语 · 26｜词汇与短语 · 58｜背景与话题 · 2
     - 每行 = 内容标题 + 标签（难度 1–5 · 置信度 高/中/低 · 来源 · 状态：未开始/进行中/已完成）。标签沿用用户已定的「置信高做题、低做资料，入口标难度置信和来源」。
  6. **新到内容**横条（仅在有新资料时出现）：列出最近接入的听力组、Task 2 新题、九分阅读，各带状态标签（如「原音待核查 · 可作阅读资料」），新资料由此直接进入已有内容库，不另开专区。
  7. **学习项目**（组合入口）放在索引最后，一组普通分组，不再单独强调。
- **找到具体内容**：滚动到分组直接点行；或搜索；或按分组顶部的筛选条（科目 / 难度 / 置信 / 状态）过滤。**分组不折叠、不套卡片**，一行就是一个内容。
- **进入内容**：点行 → 该单元页（学习、作答、精读按单元自身结构）。
- **返回**：单元页顶部一条面包屑「← 学习 · 阅读」，点击回学习页并定位到原行位置。侧栏「学习」随时可回。

### 3.2 单词

- **入口**：侧栏第 2 位 / 手机底栏第 2 键。
- **首屏**（第一屏就是操作，不是说明）：
  1. **到期条**：一行。「今天到期复习 12 词 · 开始 →」。0 到期时显示「没有到期单词 · 全部加练 →」。
  2. **我的单词表**：列表直接可见（收藏数计入页头一行小字，不单开统计卡）。每行 = 单词 + 状态（不会/模糊/会）+ 来源标签（「词卡 · 旅游」/「正文 · 《材料名》」），点行展开释义、原句、取消收藏。
  3. **新学词卡**：一个分区入口「1000 话题词卡 · 30 话题 →」，进入现有词卡页（搜索/筛选/分页保留）。
  4. **查词历史**：分区入口，进入现有历史页（含导出）。
  5. **我的词汇资料**：分区入口。
- **返回**：单词页为一级页，无「返回」歧义；词卡/历史子页顶部「← 单词」。

### 3.3 复习

- **入口**：侧栏第 3 位 / 手机底栏第 3 键。
- **首屏**：到期队列一览，**每一行就是一个可直接开始的复习动作**：
  ```text
  复习
  ─────────────────────────
  今天到期
   单词复习    12 词到期    开始 →
   句子重看     5 条收藏    开始 →
   精读回顾    昨天读过《食糖的历史》  回到精读 →
  ─────────────────────────
  全部队列（不到期也能练）
   单词加练 · 句子本 · 最近 7 天读过的材料
  ```
- 单词复习进入现有「复习与拼写」流程（提示、判定、暂停保留）。句子重看点行即跳到句子页对应条目。精读回顾回到同一材料的精读区（落实「做完材料回到具体词句精读」原则，不写空话）。
- **本页不做事**：不评掌握度、不打分、不设连续打卡。

### 3.4 句子

- **入口**：侧栏第 4 位 / 手机底栏第 4 键。
- **首屏**：搜索条 + 句子列表直接可见。每条 = 原句 + 译文 + 「来自《材料名》」来源链接。
- **回原文**：点来源 → 同一材料页定位并高亮该句 → 材料页顶部出现「从句子本回来 · 返回 →」条（承接 P0-03 契约；历史无来源句子如实标「来源未记录」，不伪造链接）。
- **返回**：「← 句子」回列表原位置。

### 3.5 练习

- **入口**：侧栏第 5 位 / 手机「更多」第 1 项。
- **首屏**：四科 + 写作分 Task 的平铺分组列表，形式与「学习」索引一致（分组小标题 + 内容行），数量标在组标题后：听力 10｜阅读 56｜Task 1 · 11｜Task 2 · 20｜口语 3。行标签含题型、难度、置信、来源、完成状态。顶部同一搜索框（限定练习范围）。阅读练习行的精读入口标在行内「含同材料精读」标签，不是再一层。
- **进入/返回**：同 3.1 约定，面包屑「← 练习 · 阅读」。

### 3.6 测试

- **入口**：侧栏第 6 位 / 手机「更多」第 2 项。
- **首屏**：五个直列项：听力整科 · 阅读整科 · 写作整科 · 口语整科 · 四科组合。每项一行小字写明来源与当前状态（未开始/进行中/历史 N 次）。页面顶部一句固定说明「测试独立计时与记录，与学习/练习答案互不影响」，只出现一次，不每科重复。
- **新题测试**：在逐题核查与曝光控制完成前保持不可用，不列入本页（内容治理边界，不由前端伪造）。

### 3.7 写作工作台

- **入口**：侧栏第 7 位 / 手机「更多」第 3 项。**直达**，不再经过工作台八卡。
- **首屏**（落实 P0-04 与 P1-13）：
  - 有进行中的题：第一屏就是「继续《题》· 当前阶段：首稿 →」卡 + 该阶段输入区，手机端从入口到能在首稿框输入 ≤1 次点击 + 一屏滚动。
  - 无进行中的题：第一屏是选题列表 = **全部写作题**（学习题、案例题、机经新题），每行标 Task 类型、难度、置信、来源；曾在其他路径作答过的题带只读徽章「曾在学习/练习作答」（只提示，不导入不合并）。
  - 介绍文字默认收起为一行 +「展开」。
- **返回**：「← 写作工作台」回选题列表；选题列表属一级页，侧栏随时可离开。阶段跳转条在手机固定可见且不遮挡输入区。

### 3.8 工作台（资料与记录）

- **入口**：侧栏第 8 位 / 手机「更多」第 4 项。
- **首屏**：平铺五行，每行直达：
  1. 我的资料（导入、预览、编辑、导出）
  2. 原始资料（资源目录：原件、文字题目、44 个教学单元目录；保留现状混放，本方案只承诺入口直达，目录内部整理解耦为后续内容工作，不在本轮冒充完成）
  3. 记录与备份（导出整册、恢复、首次作答记录；明示「记录保存在本设备，换设备需导出备份再导入」）
  4. 定制课程 · 待开放（一行窗口说明 + 「暂不开放」状态，**不进入学习索引、不进入每日安排、不占任何学习任务**）
  5. 开发与维护（GitHub 仓库、发布记录外链，原「开发工作台」内容原样保留）
- 原工作台八卡中的「写作工作台 / 单词表 / 句子本 / 今天选的内容」四个快捷入口**移除**（已各自有更好的一级或学习页位置）；旧深链全部有效（见第五节兼容）。

## 四、场景点击预算

点击预算从「任意页面」起算，滚动不计点击。桌面与手机同预算。

| 场景 | 路径 | 点击数 |
|---|---|---|
| 找一份新阅读材料 | 学习 → 搜索输入「糖」或直接看「新到内容」横条 → 点《食糖的历史》行 | **2–3**（现状：学习 → 阅读分类卡 → 分类页 → 找条目，且新材料可能在原始资料里，4+ 且不确定） |
| 复习今天的单词 | 复习 → 单词复习「开始」 | **2**（现状：工作台 → 记录页 → 内嵌单词表 → 复习区，4 且要穿过整张记录页） |
| 写一道新题 | 写作工作台 → 选题列表点新 Task 2 → 落到首稿输入区 | **3**（手机 ≤1 点击 + 一屏滚动到输入区；现状手机输入区在约 2395px 处） |
| 回句子原文 | 句子 → 点「来自《材料名》」→ 材料页高亮该句；顶部返回条回句子本 | **去 2、回 1**（现状：句子本无来源，回不去） |
| 接着上次学 | 学习 → 「继续上次」行 | **2** |
| 做一组阅读练习并精读 | 练习 → 阅读分组点题组行 → 题后精读在题页内 | **2** |
| 导出一整册备份 | 工作台 → 记录与备份 → 导出 | **3** |

预算上限规则：**任何学习内容 ≤3 次点击**；高频四件（学习/单词/复习/句子）**≤2 次点击到达主动作**。新增内容接入时若任一场景超标，视为入口设计回归，须先修入口再发布。

## 六、手机（390px）专项规则

针对用户「一托依托」的具体指向，手机端四条硬规则：

1. **不卡片套卡片**：内容索引一律用「分组小标题 + 行列表」，行间用分隔线，内容行不再有卡片边框、阴影、内嵌卡片。首屏只允许最多一张「继续上次」提示条。
2. **说明不占首屏**：所有页首说明默认收起为一行 +「展开」；计数并入筛选行；页头标题一处（面包屑内不再重复同标题，落实 P1-12）。

## 八、可验收准则

交付验收逐条打勾，桌面 1440px 与手机 390px 双尺寸各验一遍；保存后刷新恢复；旧记录兼容。

**结构**

1. 全局导航恰好 8 项，文案与 2.1 一致；手机底栏恰好 5 键，「更多」抽屉恰好 4 项平铺。
2. 单词、复习、句子、写作工作台四点均为一级入口，从任意页面 1 次点击到达。
3. 「今天选的内容」「直接开始」「开发工作台」不再出现在一级导航；其功能分别从学习首页和工作台可达，深链有效。

**第一屏**

4. 八个一级入口的第一屏（390px 不滚动可见区）均无整段说明文字；说明均收起为一行 + 展开。
5. 学习首页首屏可见：今天条、搜索框、至少一个科目分组及 ≥3 行内容；单词页首屏可见单词表 ≥3 行；复习页首屏可见全部到期队列行；句子页首屏可见 ≥3 条句子及来源；写作工作台有进行中题时首屏即当前阶段输入区。
6. 手机端学习/练习索引零卡片嵌套：内容行无卡片边框内套卡片；同一标题在一屏内只出现一次（P1-12 回归）。

**可达性（点击预算）**

7. 第四节七个场景逐一实测，点击数不超过预算；任何学习内容从任意页 ≤3 次点击。
8. 手机写作工作台：从底栏/抽屉入口到首稿框可输入 ≤1 次点击 + 一屏滚动（P1-13 回归）。

**兼容与记录**

9. 第五节表内全部旧 `#route` 逐一打开，内容、字段、媒体与基线一致；`#records` 内原单词表/句子本位置只剩跳转提示行，数据仍由独立页读写同一份。

11. 定制课程仅出现在工作台一行，不出现在学习索引、每日安排、复习队列或任何任务列表。

**防回归**

## 九、明确的边界（本方案不做什么）

- 不增加第 9 个一级入口；「常用独立呈现」以 8 项为上限，其余靠学习页搜索与分组承载。

- 不引入评分、打卡、掌握度百分比等健康原则已排除的元素。
