# 控制器启动与输入刷新优化 · 2026-09-21

本目录是独立候选及隔离测试，不代表正式册或公网已经更新。最终集成与浏览器验证由主任务统一完成。

入口：`tools/runtime_performance.py` 的 `transform(html) -> html`。只转换字符串；不发布、不改保存字段、不读取用户学习记录。可以接在媒体和工作台变换之后；同一结果重复调用返回原文。源码锚点不匹配时拒绝继续，避免把其他版本的脚本静默改坏。

## 已做

- 1000 张话题词卡保留原 DOM 和 2000 个保存控件；搜索索引每批最多 50 张，空闲时逐批处理，进入词汇时提升到逐帧处理。准备期间显示进度，不把尚未建完的索引显示为零结果。
- 每卡五次局部查询改为一次联合查询；2000 个逐卡 change 监听改成一个容器委托监听。翻页只隐藏上一页并显示下一页，完整一页最多 50 次 hidden 写入。
- 词数和评分输出建立静态索引；输入后仍立即保存，仅刷新受影响的字数／评分。
- learning-adjust 缓存字段、单元进度结果、进度容器和门控键；输入或记录提交使进度缓存失效。隐藏区不重建进度条；路由进入时刷新。门控真正打开时仍同步读取所有必需答案并验证保存。
- 合并同帧视图刷新，在排队时设置标志，累计这一帧涉及的所有测试和 Part。旧章节摘要也合并同帧请求。首页不再先全量绘制后又按路由绘制一次。

核心记录写入时序、首答快照、答案门控、冲突保护、3353 个保存字段、daily 和健康脚本保持原有逻辑。没有卸载或重建材料字段，也没有实现跨设备云同步。
