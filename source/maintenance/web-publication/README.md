# 雅思学习册公网发布副本

此目录是独立发布项目，正式内容仍以工作区 README 指定的本地学习册为准。
不要从此目录反向覆盖本地正式册，不要运行旧整页重建器。

## 更新

在上一级工作区运行 `./prepare_web_publication.ps1`。它读取最新正式册，沿 HTML/CSS 引用收集依赖，同时补齐词典动态加载文件，重新生成 `dist/`。
只删除并替换本项目的生成目录。原本地学习册和浏览器记录不受影响。

准备成功不代表已上线：后续必须将本项目推送到对应托管源仓库，并完成发布；以平台返回的成功状态和同一正式网址为准。
托管版部署后由云端提供服务，本机和本地预览服务均可关闭。学习内容变更需要再次发布。

音频/PDF 网页副本只替换匹配 SHA-256 的指定原件。以后更换这些材料时，必须重新生成并验证副本，不能沿用旧内容。
`publication-manifest.json` 保存本次正式册指纹、实际保存字段数量、全部原始输入与发布资源指纹、转换资源映射。
由脚本动态生成的媒体入口需登记在 `extra-resources.json`，绑定已审核源文件的 SHA-256。当前含机经批次的两个资料页和完整听力；音频网页版使用独立的 `jijing-audio-preparation.json` 映射，完整解码时长与原件一致。

## 保持学习记录

网站更新沿用保存键、题目身份及同一网站域名。普通更新不会主动清空浏览器里的记录。
电脑与手机的浏览器存储彼此独立，内容发布流程不提供个人记录云同步。
从本地文件首次迁移到 HTTPS 域名，需要在原页面导出，再在新网站导入：

- 整册记录：原页面的记录备份，包含答题、单词、句子、写作和每日学习。
- 定制课程：使用定制课程自己的导出/导入。
- 我的新增资料：使用资料自己的导出/导入。
- 录音：当前仅在页面内存中，需下载音频文件单独保存。

没有读取或打包任何实际浏览器记录。`dist/` 不包含构建脚本、源审计报告、工具或凭据。
手机可添加到主屏幕；此版本不承诺离线可用。

网页版词库保留全部 770,611 词目，将 702 个数据分片无损压缩后按需加载，浏览器通过 DecompressionStream 解码（需要较新的浏览器）。`node check-dictionary.cjs` 在隔离环境检查实际发布引擎和词形查询。
平台限制为单文件 25 MiB、整个展开包 256 MiB；构建器会提前检查，超出时停止发布并保留线上旧版。
