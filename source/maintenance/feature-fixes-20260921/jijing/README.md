## 难度依据

`difficulty.json`的1–5是同科内部的粗略编辑等级，越高表示题面与材料的任务负荷越高。参考语言/抽象度、信息或观点整合、作答结构，不按来源热度、未知样本正确率或个人学习记录自动换算。各项都有具体理由；未强求覆盖所有等级。

核对题型和评价边界时参考了[IELTS听力格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening)、[IELTS学术阅读格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)及[IELTS学术写作格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)。这些说明支持题型、完整Task 2的250词与约40分钟条件，以及写作的任务回应、连贯、词汇、语法维度；不提供本项目的1–5材料难度。

官方[成绩说明](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)使用IELTS Band描述考生表现。本项目难度既非官方Band，也非个人掌握度、命中率或统计正确率；缺少同水平样本校准。
