## 接入接口

维护源是 `tools/workspace_split.py`，可直接调用纯函数：

```python
from tools.workspace_split import transform as split_workspaces
html = split_workspaces(html)
```

推荐先运行该函数，再运行并行的性能改造 transform 和媒体外置；它要求现有 workspace 导航和 learning-adjust owner 边界仍存在。若边界变化会报错，不默默覆盖。重复调用已完整接入的候选不再变更。

独立 CLI 只能写不同于 source 的路径：

```text
python tools/workspace_split.py SOURCE.html CANDIDATE.html
node content-pipeline/workspace-split-20260921/qa.cjs [CANDIDATE.html] [BASELINE.html] [REPORT.json]
```

QA 三个参数均可省略，默认此目录 candidate.html、当前正式册、此目录 qa.json；合并后应传入最终候选与原基线重跑。QA 复用已有 `qa_navigation_ui_final.cjs` 的隔离 DOM 引导段，不操作用户浏览器记录。此工具没有读取用户凭据，开发页只有两个固定公开链接。
