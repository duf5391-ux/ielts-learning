# 写作与口语修复 · 2026-09-21

本目录提供可组合的最小增量，不写正式册或发布仓库。受测正式基线为 `7ea735c348907a20b6b808ee403423aea263c29811071067ddca41fa85bfce44`，单独应用后的预览为 `822b07dce5e84734aa534b0d7209e7c7775a416bfac8fe10a41b8cd01d5637ad`。保留3353字段、220单元、五入口、手机媒体按需加载及记录并发保护。

## 已修复

- 写作保留首稿原先依次保存时间戳、暂停计时、复制修订稿。修订保存失败后首稿仍被锁定。现在一次调用现有记录提交，成功后才锁编辑器和更新时钟；失败后可以继续编辑和重试。
- 计时保存失败原先先改变隐藏字段，随后其他输入可把未启动的计时写入。修订版本保存失败也有同类残留。现在失败保留原工作流元数据。
- 写作冻结前校验当前可见首稿、修订、冻结时间与计时字段。另一标签修改修订时，本页不再先锁首稿；保留对方记录和本页草稿。此为保存冲突保护，不是localStorage跨进程事务。
- 口语在麦克风权限请求时立即锁定本次开始按钮，启用结束按钮；请求可取消，迟到授权会释放轨道而不开始录音。阻止同时开多个录音及重复停止。
- 录音初始化失败释放已经取得的麦克风轨道，权限拒绝有具体说明；录音错误尽量保留已收到的片段。
- 下载扩展名跟随实际MIME；MPEG4用m4a，不一律webm。录制和载入都保留用户已有笔记，不用文件名覆盖。
- 录音及权限请求阶段沿用可用的`data-stop`控件，原健康休息/收工检查可识别；离页前对录音中或尚未发起下载的音频启用浏览器提醒。
- 原全局`audio{display:block}`覆盖`hidden`，刷新后会显示空播放器。新增仅限录音区的隐藏规则。

## 接入方式

根集成器通过importlib导入本目录`integrate.py`，调用`apply(current_html)`。函数幂等，精确替换写作脚本标记、旧录音块，并为`IELTSRecordStore.commit`增加可选`options.expectedFields`透传；其余核心代码和内容不重建。正式备份、并发指纹比较及发布由根集成器执行。

维护源：工作区`writing-workbench.js`与本目录`speaking-recorder.js`。如果未来重建核心，必须在之后重用本目录增量。不要只替换写作脚本而遗漏记录提交参数扩展。
