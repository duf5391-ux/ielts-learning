# 单词整合与双端 UI · 2026-09-22

按用户最后的纠正：单词首页直接背词，最多按话题选择；复习接续查过或学过的词；句子也属于单词。此前八个一级入口方案不再适用。

一级入口为学习库、单词、专项练习、自测、写作训练、资料与记录。单词内部为背单词、复习、句子、查词与历史；历史页内可切查词记录、学习记录及已收录词语。旧深链保留。

`build.py` 从 e2b9 最新完整产品版增量构建，不重跑历史整页生成器。`word-learning.js` 使用现有1000词卡、30话题，默认直接出现下一个未学词；不会/模糊/会均可直接点击。看过释义后刷新也保留短期曝光标记。一次自评只写 N 新学，不自动改成 K 已会用。旧已标记词接入复习时不补造日期和作答。

复习继续使用已有回忆/拼写和间隔机制，队列改为全部查过或学过的词；重点收藏只作为重点标记。拼写自测属于加练，保留具体输入、提示状态和结果，不冒称能力分数。`history.js` 读取同一词记录中的真实事件。句子沿用原字段、编辑和回到原句能力。

4091旧字段、2460旧ID、111媒体节点保持，新增1个背词状态字段，共4092。原236目录单元不改变。备份在 `formal-backup`；`installation.json` 绑定原件、备份和候选指纹。

`verify.cjs` 在隔离浏览器中检查直接学习、话题、刷新、失败回退、查词自动进复习、拼写结果、历史、旧记录、24个双端页面及健康休息；`verification.json`、`packed-verification.json`、`live-verification.json` 分别对应本地候选、渐进加载发布包、实际HTTPS。合成记录不写入用户浏览器。桌面1440×1000、手机视口390×844不等同于真机。

`interface-tensor.html` / JSON 从当前源码提取入口×内容×活动×保存归属，4383节点、4395关系。字段为契约，没有个人记录；它补充而不代替旧原料→片段→活动关系图。Kimi早期报告基于八入口旧设想，仅采纳适用的可读性建议，用户最新单词整合要求优先。

发布与公网边界以 `research/product-word-workspace-delivery-20260922.md` 为准；源码快照随后同步原源码分支。
