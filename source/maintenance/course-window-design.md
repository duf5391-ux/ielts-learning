# 从用户材料到阶段化学习窗口

这是新增功能的课程设计约定。以后用户给出技巧、语料、词汇或组合材料时，系统据此编写来源可靠、用途明确、贴近考试实际要求的教学与练习。**双向拟合的两端是用户材料与考试要求，重点是选材质量与教学、练习的适配程度，不是保证每批输入足够覆盖考试。** 学习记录用于调整教学，是额外反馈环节。`course-window-seed.json` 是演示课程，明确标记为 `status: sample`；旅游迁移题以官方 Task 2B 为来源进行局部改编，其余微题和所有教学支架、参考答案均为本课编写，调查数据均为虚构练习数据。

## 双向拟合的含义

**材料 → 考试应用**：保留用户给出的表达、含义、上下文、使用边界与原要求，判断它能帮助完成哪种考试任务，以及在任务里起什么具体作用。例如把 `contribute to` 放进一个与题意有关的支持句，而不是不论题目是什么都要求使用它。每道题用 `targets` 指向材料，用 `examTargets` 指向考试要求，用 `examUse` 说明实际用途。关系必须体现在题目、答案与检查点中，不能只是多贴一个考试标签。

**考试要求 → 选材与练法**：以真实考试任务约束选材和教学。例如利弊权衡题需要比较后果，不能只练两个表示因果的短语；就应选择能讨论具体影响的语料，并安排解释机制、判断比较条件的产出。关联不强的内容不强塞进题型，不为了“覆盖完整”添加大量材料。说明本窗口的适用范围即可；缺口只是边界提示，不是这批材料不合格的判定，也不是强制追加完整考试课程。

**学习反馈 → 下一窗口**：先看实际答案、错误类型、提示使用情况和解释，再调整讲解、难度、练习形式、时长与语境。用户答错也可能是题目材料不足或答案不唯一，不应自动归因为能力不足。既有对话与学习记录可以帮助选目标，但推测不能变成已确认的个人能力；用户可以纠正系统判断。

## 选材原则：质量与用途优先

先明确用户这批输入希望学会什么，再查找与其用途相符的题目或情境。用于证明考试拟合度的材料，应尽量可追溯到官方样题、已核对的真实试题或官方教学实例；仅引用评分标准、把自拟题命名为“IELTS 式”不能单独证明选材质量。选择理由必须落到原题的对象、作答动作、关系和限制上，不只是同话题或包含同一个词。

来源可靠并不自动等于适合这批材料。官方题也要经过相关性检查；需要搭桥时可以新增示例、反例和拆解练习，并明确哪些来自原件、哪些是教学改编。自编内容可以提供更有针对性的支架，但不能冒充官方语料或真实研究。用户自己的材料仍保留原意与边界，不被官方题覆盖掉。

本示例据此选择[官方国际旅游 Task 2B（第 7 页）](https://ielts.org/cdn/Sample-tests/ielts-academic-writing-sample-tasks-2023.pdf#page=7)：原题要求判断利弊孰重，需要说明旅游如何影响当地居民和环境，适合训练 `contribute to`、`lead to` 的作用机制表达。改编保留这个比较要求，将产出缩为两句；就业、垃圾的提示与参考写法由本课新增，并不属于官方原题的已知事实。

## 考试依据与示例边界

示例选取 IELTS Academic Writing Task 2。官方说明要求完整任务至少 250 词，建议约 40 分钟，并允许用个人知识或经验中的例子支持观点；不要求科学调查或引用文献。本课的调查语料只是练习准确处理给定信息的一种方式，不代表真实考试必须寻找统计资料。[IELTS 官方考试形式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing)

本课关联的维度是 Task Response 中观点的相关展开与支持、Lexical Resource 中恰当准确的词义与搭配，以及少量 Grammatical Range and Accuracy 中的结构准确性。微练习只观察这些维度的一小部分，不能据此给分；全文 Coherence and Cohesion、完整立场与语言范围仍是缺口。[IELTS 官方写作评分描述](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)

课程的 `examAlignment` 包含考试、科目、题型、要求、官方来源、未覆盖项和本次范围。所有示例任务的 `practiceMode` 均为 `micro`，包括 60–80 词段落练习及官方题下的两句比较练习。旅游题另用 `materialSourceIds` 指向官方题来源，并用 `adaptationNote` 说明保留、改编和新增内容。评分维度来源与原题来源分别承担各自的证据作用，不把参考段落标成官方。

## 一次学习窗口的最小完整单位

窗口包含原始输入、此次能完成的具体目标、材料条目与边界、考试用途与未覆盖要求、阶段任务、参考答案和判断依据。总时长是估计，允许用户调整。示例采用 15 分钟练习预算：起点诊断 2 分钟、理解边界 3 分钟、带支架练习 4 分钟、独立迁移 4 分钟、下一次回访 2 分钟；需要更长阅读或组织时间时可以延长。回访属于这份课程的总工作量，但不应暗示必须在同一次连续学习中做完。

1. **起点诊断**：先让用户在未见答案的情况下处理一小段材料。允许熟悉的同义表达，不以使用指定新词作为成功条件。记录“会选”与“会独立写”两个不同证据。
2. **理解边界**：给用户材料对应的具体讲解、一个正确例子和一个不适用情境。解释为什么不能用，而不只解释怎么用。
3. **带支架练习**：给句型提示、检查点或部分步骤；以修订答案观察用户能否发现信息变化和形式错误。提示后的表现不能当成无提示掌握。
4. **独立迁移**：换主体、话题或信息关系，把材料放进真实题型的要求里。示例要求为 Task 2 的一个观点写出理由、解释与例子。不能只换几个名词再做复述，也不能规定把不适用的词全部使用一遍。
5. **稍后回访**：在实际间隔后做新题，保留作答时间。即时做完只算即时练习，不虚构间隔、记忆保持或长期掌握。

阶段可以根据证据缩短、重做或暂缓。每项任务都需要可作答的短文或足够的情境；不能只写“换一个情境试试”就把课程交付给用户。

## 根据答案作出具体调整

下表是应当支持的设计规则，不等同于声称浏览器已具有自动语义批改能力。无法可靠判断时，显示待复核，并提供对照点；允许用户或助教根据实际答案确认。

| 观察到的证据 | 下一窗口的调整 | 不能据此推断 |
|---|---|---|
| 选择题正确，但独立写句困难 | 保留目标，补一个短句组织示范，再换例子让用户独立写 | 已经能在真实写作中运用 |
| 词义大体正确，`to` 后的形式反复出错 | 加入两组真实上下文的名词 / -ing 对照，并安排一次无提示产出 | 所有语法基础薄弱 |
| 表达流畅，但把关联写成因果 | 优先补证据边界和反例，要求指出依据，再做不同主题的题 | 只需背更多同义词 |
| 总是添加 `may`，连明确结果也改成猜测 | 加入明确因果与预测的成对情境，要求分别报告 | 保守措辞总是更准确 |
| 同一材料上正确，新主题又误读指标或范围 | 改写资料以突出信息核对；新题更换指标和关系方向 | 已完成迁移 |
| 题目缺乏上下文，用户给出多种合理解释 | 先修题并承认可接受答案；此题不用于降低学习状态 | 用户没有掌握目标 |
| 用户指出输入语料不是自己想学的用法 | 回到原始材料和要求，修订条目、例子、题目和边界 | 用户否认既定教学结论 |
| 用户在无提示新情境中准确作答并解释边界 | 减少重复讲解，把练习转向另一材料或更独立的任务 | 已获得某个 IELTS 分数或永久掌握 |

下一窗口应明确写出“根据哪条答案做了什么调整”。不同错误应产生不同的任务或支架；仅改变推荐文字、仍反复展示完全相同的练习，不算完成学习反馈闭环。材料与考试的双向拟合还必须单独展示考试用途和覆盖缺口。

## 材料不足时怎样继续

只有一个词时，可以先做词义辨析、常见结构和条件明确的示例；把原材料与系统补充内容区分开，并让补充内容服务于指定考试任务。考试需求若要求完整论证，就另外补充观点、解释、相关例子与段落任务，不能假设词义练习已经覆盖。语料缺出处、上下文或用途时，不臆造原作者含义，可以明确采用一个临时语境并允许用户纠正。技巧过于宽泛时，把它拆成可观察的动作，例如“找出限制范围的词，并说明它限制谁”；不能只让用户抄写技巧名称。

若材料存在错误或与需求不匹配，应指出具体问题并修订课程，不默默替换用户意图。缺少足够题材时，可补充明确标记的自编情境；缺少用户作答时，只能提出诊断任务，不能生成假的薄弱点、完成记录或学习轨迹。

## 记忆、理解、运用分开记录

- **记忆证据**：能不看笔记说出词义或结构。重复见过的选择题最多提供有限证据。
- **理解证据**：能解释为什么一个表达适用，另一个会改变信息；能处理反例。
- **运用证据**：在有足够上下文的新任务里，独立选择准确表达并完成具体目的。
- **回访证据**：在记录的实际间隔后重新完成任务；与即时成功分别保存。

打开答案、勾选学过、输入目标关键词、完成一次选择题，都不能自动标记为熟练运用。参考答案只是一种准确写法；文本任务依据 `rubric` 的信息与语言检查点评估，接受等义答案。自动比较可报告客观选择题的对错，不应把字符串匹配包装成文本语义判断。

## 示例课程的可追溯关系

示例的五个条目分别是 `contribute to`、`lead to`、`be associated with`、核对信息与确定程度的技巧，以及学院图书馆调查语料。练习有意区分“词组的含义”和“完整句子的确定性”：`contribute to` 仍可能表达因果，`could lead to` 可以表达预测，`be associated with` 也不能虚构不存在的数据。

原语料的调查题用于首次诊断和修订；迁移题换成社区花园与孤独感，围绕自拟公共投入题展开一个正文段落；另一题以官方国际旅游 Task 2B 为依据，要求用关系表达说明收益与代价，并作局部比较。前者提供控制明确的教学情境，后者展示与实际发布题目作答要求的对应。回访换成错误原因与尚未测试的冷却系统。

本组材料适合局部选词、因果句法、观点展开与后果比较。它没有训练全文组织和限时整篇写作，这只是本次范围，不需要为了凑齐覆盖而扩大窗口。衡量这项功能的关键是：后续任一批用户材料能否得到忠实、有依据、与具体考试用途高度相关的教学与练习。
