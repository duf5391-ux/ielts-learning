在网站使用这台设备的 AI

网站连接本机的 Codex、Ollama 或 LM Studio。每台设备保存自己的接口和模型选择；对话保存在该设备的连接器目录。

下载本机连接器

第一次使用

  1. 解压下载包。Windows 用户运行包内的“启动连接器.ps1”。启动器会查找已安装的 Node.js，以及 Codex 自带的 Node.js 运行时。其他系统可在解压目录运行 node server.cjs。
  2. 打开写作题，展开“问本地 AI”，点击“连接本机 AI”。选择你要使用的服务。
  3. Codex 使用本机已有登录；Ollama、LM Studio 使用各自已启动的本地服务，在窗口里读取并选择模型。
  4. 点击“保存并连接”。浏览器出现本机网络访问提示时，允许本站访问本机。连接确认后即可发送。

已有本机陪练

已在本机运行 IELTS 陪练的用户可直接连接现有 http://127.0.0.1:8831。这台电脑当前的常驻启动会继续维护该地址。

服务与模型

  • Codex：短任务与中文写英文使用 GPT-6.1 Sol · medium；完整讲解使用 Astra · high，深入任务按请求提高至 xhigh。
  • Ollama：默认模型服务地址为 http://127.0.0.1:11434/v1。
  • LM Studio：默认模型服务地址为 http://127.0.0.1:1234/v1。
  • 其他 OpenAI 兼容服务：填写本机接口地址和模型名称，支持无 API 密钥的本机服务。带题图的问题需要所选模型具备看图能力。

连接与记录

连接器仅监听本机回环地址，接受本站正式域名与已有本地预览。选择 Codex 时，题目和稿件交给本机 Codex 登录所使用的模型服务处理；选择本地模型时交给相应本机服务。学习进度继续由网站账号保存，对话和中文原稿由本机连接器保存。

连接失败时，先确认连接器与所选模型服务正在运行，再到浏览器的本站权限设置中允许“本机网络”或“Loopback network”访问，然后重新连接。
