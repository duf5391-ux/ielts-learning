# 命名与视觉复核（Kimi K3，仅建议，2026-09-22）

已读 navigation.css、product-entry-decisions，亲看 before-390-study / before-1440-study 截图。

## 1. 八个入口最终命名（route → 建议名）
1. study → **学习**（保留）。「学习库」的"库"偏浏览仓库，弱化了该页"直接开始"这个主动作；底栏首项也不宜长。
2. vocabulary-review → **单词本**。采纳；落地页是我的单词表，"本"准确，比"单词"更贴。
3. word-review → **单词复习**。采纳；复习只有单词回忆/拼写，必须带"单词"限定，避免暗示有句子到期队列。与"单词本"同前缀相邻，可接受。
4. sentence-learning → **句子本**。采纳，与单词本成对。
5. practice → **专项练习**。采纳；"专项"与自测区分开。
6. tests → **自测**。采纳；诚实——这是训练自测，不是官方模考或能力认证，禁用"模考/认证"类词。
7. writing-workbench → **写作工作台**（保留，不改为写作训练）。专项练习里已有写作 Task 1/2 题组，"写作训练"与之易混；"工作台"传达首稿-检查-修订的流程属性，是该入口的差异点。
8. workspace → **资料与记录**。采纳；与页内大标题一致，消除"工作台/资料与记录"两名并存，也让"工作台"一词专属写作。

## 2. 五条可直接实现的视觉规则
1. **间距**：统一 8px 基网格——行内上下 padding 12px、组间距 26→32px、meta 与标题间 4px；手机行 padding ≥10px，不让列表贴边。
2. **字层级**：全站只三级——页标题 26–28px/650、组标题 15px/650、条目 15px/550，meta 11px；手机 23/13/14/10。词表卡 h3 的 19px 归入条目级，消灭游离字号。
3. **行式列表**：保持无卡片、无阴影、单分隔线（#e1e7df）；整行可点，hover 加底色 #f3f6f0 提示可点，不加圆角堆叠。
4. **导航当前态**：桌面侧栏深绿填充白字、手机底栏顶部 3px 绿条+深绿字，两处当前色统一 #285540；所有可点元素 focus-visible 3px 外描边。
5. **手机**：触控目标统一 ≥36px；分类行改单行横向滚动（现 390px 占两行，可省一整行给内容）；底栏 54px+safe-area 固定，正文 padding-bottom 让位。

## 3. 三条应避免
1. 避免引入新色、渐变、阴影卡片风——保持暖白+深绿，防止重回一层套一层。
2. 避免为凑美感压缩题干/长句，或把状态与操作藏进 hover-only——手机没有 hover，完整句子优先于行数指标。
3. 避免图标化（无文字）导航与新增悬浮按钮——文字标签才清晰；新浮层会与每日 dock、手机底栏打架。
